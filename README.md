E-Learn Platform Frontend
A modern, responsive frontend implementation of an E-Learning platform based on the provided epics and user stories.

Features Implemented
EPIC 1: User & Access Management
User Registration: Email and password registration for learners and instructors with modern form design.
Login & Role-Based Access: Secure login with roles (Admin, Instructor, Learner) and smooth navigation.
EPIC 2: Course Management
Course Creation & Management: Instructors can create, publish, unpublish, and delete courses with intuitive UI.
Course Enrollment: Learners can browse and enroll in published courses with card-based layout.
EPIC 3: Progress & Assessment
Progress Tracking: Track lesson completion and display progress with animated progress bars.
Quiz & Certificate: Basic quiz functionality with modern styling and certificate simulation.
Modern UI/UX Features
Responsive Design: Works seamlessly on desktop, tablet, and mobile devices.
Modern Aesthetics: Gradient backgrounds, rounded corners, shadows, and smooth animations.
Intuitive Navigation: Sticky header with icon-enhanced buttons.
Comprehensive Dashboard: Role-based dashboards with statistics, quick actions, and personalized content.
Course Enrollment Widgets: Visual course cards with progress tracking and enrollment buttons.
Achievement System: Gamification elements to motivate learners.
Instructor Analytics: Course management overview with student counts and ratings.
Admin Overview: Platform metrics and user management tools.
Form Enhancements: Labeled inputs with icons and focus states.
Interactive Elements: Hover effects, transitions, and visual feedback.
Dashboard Features by Role
👨‍🎓 Learner Dashboard
Welcome Header: Personalized greeting with role indicator
Quick Stats: Enrolled courses, completed courses, overall progress percentage
Action Buttons: Browse courses, view progress, manage enrollments
Continue Learning: Resume courses with progress bars
Recommendations: AI-suggested courses based on interests
Achievements: Gamified milestones (First Steps, Course Complete, etc.)
👨‍🏫 Instructor Dashboard
Welcome Header: Professional greeting for educators
Quick Stats: Total courses, student count, average rating
Action Buttons: Create courses, manage existing courses, view analytics
Course Overview: Published vs draft courses with enrollment numbers
Recent Activity: Student enrollments, ratings, quiz completions
👑 Admin Dashboard
Welcome Header: Administrative overview
Quick Stats: Total users, published courses, enrollments
Action Buttons: User management, course oversight, reports
Platform Overview: User distribution charts, recent registrations
Management Tools: Role assignment and platform analytics
How to Run
Open index.html in a modern web browser.
Register a new account or login with existing credentials.
Explore the dashboard and features based on your role.
Technologies Used
HTML5
CSS3 (with modern features like Flexbox, Grid, and CSS Animations)
JavaScript (ES6+)
Font Awesome for icons
Google Fonts (Roboto)
Notes
This is a frontend-only implementation using localStorage for data persistence.
Passwords are base64 encoded (not secure for production).
For a full application, integrate with a secure backend API for authentication and data management.
The UI is fully responsive and follows modern web design principles.
